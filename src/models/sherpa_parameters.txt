Cases for Dense layers
| Case           | Type           | Effect          | Risk                      | Typical Use        |
| -------------- | -------------- | --------------- | ------------------------- | ------------------ |
| hidden < dense | Expansion      | More expressive | Overfitting               | Large datasets     |
| hidden = dense | Identity width | Stable          | Moderate                  | Safe default       |
| hidden > dense | Compression    | Regularization  | Underfitting if too small | Often best for EEG |
